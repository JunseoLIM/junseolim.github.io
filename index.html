💡 서버 비용 0원으로 평생 내 웹앱처럼 쓰는 법

  1. 이 화면의 코드를 index.html 파일 하나로 저장합니다.
  2. GitHub Pages, Vercel, 또는 Cloudflare Pages(모두 무료)에 해당 파일만 올리면 나만의 https://... 주소가 생깁니다.

  4. 입력하신 잔고·계약 수·API 키는 외부 서버가 아닌 내 브라우저(localStorage)에만 안전하게 저장됩니다.
